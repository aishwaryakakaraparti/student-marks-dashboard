# SortScope – Sorting & Time Complexity Visualizer

## Project Overview

SortScope is a simple web-based project that helps visualize how different sorting algorithms work. Along with showing the sorting process, it also gives an idea of their time complexity, making it easier to understand how efficient each algorithm is.

This project was built as part of academic learning to make abstract concepts like sorting and complexity more clear and interactive.



## Objectives

- To understand how common sorting algorithms work
- To compare their performance based on time complexity
- To create an interactive tool for better learning
- To apply basic frontend development skills



## Technologies Used

- HTML
- CSS
- JavaScript



## Algorithms Covered

- Bubble Sort
- Merge Sort



##  Features

* Step-by-step visualization of sorting
* Displays execution time
* Shows time complexity (Best, Average, Worst cases)
* Allows user input for custom data
* Simple and clean user interface



##  How to Run

1. Clone the repository  
2. Open the project folder  
3. Open `index.html` in your browser  

##  Use Case

This project can be helpful for students who are learning Data Structures and want to understand sorting algorithms in a more visual and practical way instead of just theory.
